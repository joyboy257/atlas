# Packaged front-desk example

This example is a complete Atlas project embedded in `@atlas-runner/atlas`.

From this directory:

```bash
atlas doctor --json
atlas test --json
atlas dev --json
```

Open the workbench URL and send:

> Can I move booking BK-100 to Friday?

Approve the pending action, simulate provider delivery, then inspect the trace and receipt chain.

The project uses the deterministic local fixture model and simulated web-chat provider. It needs no Atlas account, provider credential, cloud service, or paid model. It proves local governance, not staging, production, or live-provider behavior.
